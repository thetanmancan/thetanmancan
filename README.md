It takes analysis to understand something technically.
It takes empathy to understand something emotionally.

I do both. I understand.

I'm Tristan Camacho, an L.A.-based experience designer. Experience design is about addressing user pain points, which involves knowing and solving for both halves of a user's problem: what is happening outside of the user and what is happening inside of the user. I care about both.
